# 수면적 ≠ 저수량 — SAR로 말할 수 있는 것과 없는 것

SAR에서 바로 나오는 값은 **수면 면적(km²)** 하나뿐이다. 그런데 가뭄 보고에서
정작 듣고 싶어 하는 값은 **저수량(m³)** 또는 **저수율(%)** 이다. 이 둘은 같은
방향으로 움직이지만 **같은 크기로 움직이지 않는다.** 이 문서는 그 차이가
얼마나 되는지를 수치로 못박고, 어떻게 써야 안전한지를 정한다.

관련: [DROUGHT_KR.md](DROUGHT_KR.md)(가뭄 판정 설계) ·
[BASELINE_DESIGN_KR.md](BASELINE_DESIGN_KR.md) ·
[WATER_AREA_KR.md](../water/WATER_AREA_KR.md)(면적 산출 실적)

> **이 문서가 생긴 경위** — 원래 이 내용은 `Korea_WaterDetection_2025_2026/README_KR.md`
> §2·§3에 있었다. 그 폴더는 gee 쪽으로 활성 개발이 옮겨간 뒤 비활성 사본으로
> 남아 있다가 2026-09-09에 제거됐다(커밋 `af052a3`). **거기서만 설명하던 두
> 가지**(수면적 ≠ 저수량, geeflood 대비)를 지금 기준으로 다시 쓴 것이다.

---

## 1. 한 줄 요약

> **SAR은 저수량을 잴 수 없다.** 면적에서 부피로 넘어가려면 그 저수지의
> **수위–면적–용적 곡선(H–A–V)** 이 있어야 하고, 그것 없이 환산하면
> **같은 −30% 면적 감소가 저수량으로는 −30%에서 −52%까지** 벌어진다.

그러므로 이 프로젝트의 산출물은 **"수면적이 몇 % 줄었다"까지만 말한다.**
"저수량이 몇 % 줄었다"로 옮겨 적는 순간 근거 없는 수치가 된다.

---

## 2. 왜 비례하지 않나 — 기하학

저수지의 수위를 `h`, 그 수위에서의 수면적을 `A(h)`라고 하면 저수량은 면적을
수위로 적분한 값이다.

```text
V(h) = ∫₀ʰ A(z) dz
```

수면적이 수위의 거듭제곱을 따른다고 두면(`A ∝ h^b`) 부피는 한 차수 높아진다.

```text
A ∝ h^b        →        V ∝ h^(b+1)        →        V ∝ A^((b+1)/b)
```

즉 **면적과 부피는 거듭제곱 관계**이고, 그 지수는 저수지 **형상**이 정한다.

| 형상 | `b` | `V ∝ A^?` | 어떤 지형인가 |
| --- | ---: | ---: | --- |
| 평평한 접시 | → ∞ | **1.0** | 벽이 수직에 가까운 인공 저수지·보 |
| 사발형(원뿔) | 2 | **1.5** | 완만한 구릉에 담수된 일반적인 댐 |
| V자 계곡 | 1 | **2.0** | 급경사 협곡을 막은 댐 |

작은 변화에 대해서는 **탄력성(elasticity)** 으로 읽는 편이 편하다.

```text
ΔV/V  ≈  ((b+1)/b) · ΔA/A        예)  사발형이면 면적 −10% ≈ 저수량 −15%
```

> **핵심은 지수 자체가 아니라 "지수를 모른다"는 것이다.** 실제 저수지는 수위대에
> 따라 `b`가 달라진다(만수위 근처는 완만하고 사수위 근처는 급하다). 그래서
> 단일 지수 환산은 **범위를 보여주기 위한 도구**이지 산출 방법이 아니다.

## 3. 얼마나 벌어지나 — 이 프로젝트 실측값으로

모른다** — 그게 요점이다.

> 관측값이고 뒤의 것은 근거 없는 환산이다. 보고서 문장을 옮길 때 이 둘이
> 섞이지 않게 할 것.

### 3-3. 면적이 0이 아니어도 쓸 물이 없을 수 있다

저수지에는 **사수위(死水位)** 아래의 **사수용량**이 있다. 취수구보다 낮은
물이라 수면적으로는 잡히지만 **공급 가능한 물이 아니다.** 가뭄이 깊어질수록
남은 면적 중 사수용량이 차지하는 비율이 커지므로, **면적 기준은 가뭄이
심할수록 실제보다 낙관적으로 보인다.**

## 4. SAR 면적 자체에 이미 붙어 있는 불확실도

위 3절은 "면적이 정확하다고 쳤을 때"의 이야기다. 면적 자체도 조건이 붙는다.
이 프로젝트에서 실제로 겪은 것들이다.

| 요인 | 무엇이 문제인가 | 실측 사례 |
| --- | --- | --- |
| **관측 범위 차이** | 두 시기의 공통 관측역만 비교해야 한다 | 한강 제약의 **21%가 관측폭 밖** → 공통 79%만 비교 |
| **임계값 이동** | 두 해 임계가 다르면 면적이 따라 움직인다 | 한강 −20.68 → −20.32 dB(+0.36) |
| **위성 교체** | 보정 차이가 계통 오프셋으로 남는다 | 한강만 **1A ↔ 1D**(나머지는 1C ↔ 1D) |
| **논 담수** | 제약 없이 세면 영농 일정이 물로 잡힌다 | 7월 탐지 수체의 **최대 44%가 논** |
| **분리도 η** | 히스토그램이 이봉이 아니면 임계가 무너진다 | 소규모 유역에서 임계가 −24 dB 아래로 밀림 |
| **DEM 결측** | DEM 밖은 무효라 면적이 조용히 줄어든다 | 낙동강 하구 **12.48 km²** |

> 한강 사례는 **분포로 갈라낸 좋은 예**다. 임계가 +0.36 dB 밝아졌는데, 두 해
> dB 분포를 재보니 뭍 전체가 같은 폭으로 밝아져 있었고 임계는 두 해 모두
> 뭍 중앙값보다 6.27 dB 아래라는 같은 자리였다 — Otsu가 계통 이동을 상쇄한
> 것이라 면적을 부풀린 것은 아니었다. 상세는 보고서 §6-3.

## 5. 그래서 어떻게 하나 — 작업 방침

### 5-1. 순서

1. **공식 저수율을 먼저 찾는다.** K-water·WAMIS·한국농어촌공사가 일자별
   저수율을 공표하는 댐이면 **SAR로 환산할 이유가 없다.** 관측값보다 정확하다.
2. **공식 자료가 없는 저수지만** SAR 면적을 프록시로 검토한다.
3. 프록시로 쓸 때도 **절대 저수율로 환산하지 않는다.** 아래 5-2 참고.
4. H–A–V 곡선을 확보할 수 있으면 그때 `A → h → V` 역산이 성립한다.
   곡선 없이는 3절의 표가 보여주는 폭이 그대로 오차가 된다.

### 5-2. 표기 규칙

| 쓸 것 | 쓰지 말 것 |
| --- | --- |
| "수면적이 **−30.5%**" | ~~"저수량이 −30.5%"~~ |
| "만수면적의 **58.9%** 수준" | ~~"저수율 58.9%"~~ |
| "면적 기준 감소폭이 가장 크다" | ~~"물이 가장 많이 줄었다"~~ |
| "저수량은 형상에 따라 −30 ~ −52%로 추정" | ~~단일 저수량 수치~~ |

**부피를 꼭 말해야 한다면 범위로 말한다.** 단일 값은 곡선이 있을 때만 쓴다.

### 5-3. 상대 비교는 살아 있다

환산이 안 된다고 SAR 면적이 쓸모없는 것은 아니다. **같은 저수지의 전년 동기
대비 변화**는 형상 지수가 두 시기에 공통이므로 **부호와 순위가 보존된다.**

```text
V₁/V₀ = (A₁/A₀)^k      k 를 몰라도 A₁<A₀ 이면 V₁<V₀ 이고,
                        A 감소폭이 큰 저수지가 V 감소폭도 크다
```

그래서 **"어느 저수지가 더 나빠졌나"** 는 SAR만으로 말할 수 있다. 말할 수 없는
것은 **"얼마나 나빠졌나"의 절대값**이다.

### 5-4. 교차검증

- **Sentinel-2 광학** — 같은 날 수면 경계 대조(구름 없는 날에 한해)
- **수위계** — 수위가 있으면 H–A–V 없이도 A(h) 관계를 실측으로 세울 수 있다
- **저수율 공표값** — 있는 댐에서 SAR 면적과의 관계를 맞춰 두면, 없는 댐에
  적용할 지역별 지수 `k`의 근거가 된다

## 6. `geeflood` ↔ `watercompare` — 왜 코드를 안 합쳤나

같은 GEE·같은 Sentinel-1을 쓰지만 **찾는 것이 반대**라서 알고리즘이 갈린다.
헷갈리면 한쪽 방법을 다른 쪽에 잘못 적용하게 되므로 표로 못박는다.

- `gee/geeflood/` — 북한 홍수(황강댐·임진강). **신규 침수**를 찾는다.
- `gee/Korea_WaterDetection_2025_2026/kwater/watercompare/` — 남한 가뭄.
  **평소 물이던 곳이 얼마나 줄었나**를 본다.

| 항목 | `geeflood` (홍수) | `kwater.watercompare` (가뭄) |
| --- | --- | --- |
| **질문** | 전에 없던 물이 어디 생겼나 | 있던 물이 얼마나 남았나 |
| **비교 방식** | before / after **변화탐지** | 시점별 **절대 수면적 스냅샷** |
| **Otsu 대상** | after − before **차분** 히스토그램 | **원본** 후방산란 히스토그램 |
| **임계 산정** | v2 단일 방식 | **3종 선택형** — `global` / `edge` / `split` |
| **상시수체(JRC)** | **결과에서 제외** — 안 그러면 강 전체가 침수로 잡힌다 | **후보를 가두는 제약으로 사용** — 물이 있을 수 있는 곳 밖을 걷어낸다 |
| **다른 제약** | 없음(변화 자체가 신호) | HAND ≤ T · 국가기본도(V-world) 기준자료 |
| **검증 기준** | JRC | **V-world 국가기본도**(2024 실측·수 m급). 북측은 JRC |
| **전처리** | 선형 σ⁰ → Frost → Vollrath γ⁰ → dB | 선형 σ⁰ → 스펙클 완화 → RTC γ⁰ → dB (`use_rtc` 토글) |
| **피해지표** | 토지피복(Dynamic World)·인구·침수심 | 없음 — 면적만 |
| **산출 단위** | 침수 면적·피해 추정 | (대권역 × 상대궤도) 수면적 |

### 6-1. 가장 자주 헷갈리는 지점 — JRC의 방향이 반대다

```text
홍수(geeflood)   JRC 상시수체를 결과에서 뺀다
                 → 안 빼면 평소의 강이 전부 '침수'로 잡힌다
                 → 즉 JRC 는 **지워야 할 것**

가뭄(watercompare) JRC/HAND 로 후보 영역을 가둔다
                 → 물이 있을 리 없는 산비탈·젖은 논을 애초에 배제
                 → 즉 JRC 는 **남겨야 할 곳의 울타리**
```

`watercompare/constraints.py`가 이 점을 모듈 주석에 직접 적어 두었다 —
*"홍수 신규 침수 탐지(geeflood)에는 jrc_mask를 쓰면 안 된다(찾으려는 대상을
지움)."* 반대로 **가뭄에는 안전하다.** 새로 생긴 수체를 볼 필요가 없기 때문이다.

### 6-2. 코드를 공유하지 않는 이유

두 패키지는 **의도적으로 cross-import가 없다.**

1. `geeflood`는 독립 프로젝트로 분리될 예정이라 부모 폴더 의존을 만들지 않는다.
2. 공유할 만한 부분(Otsu·컬렉션 로딩)은 작은 함수라 **복사가 더 안전**하다 —
   각자 폴더 상대로만 동작한다.
3. 무엇보다 **위 표처럼 기본 가정이 반대**라, 한 함수로 합치면 분기 조건이
   늘어나고 한쪽 수정이 다른 쪽을 조용히 깨뜨린다.

> ⚠ 단, 같은 판정 로직이 **두 벌 존재한다는 사실 자체는 위험**이다. 이 저장소에서
> 같은 유형의 사고가 있었다 — 한반도 판정이 두 구현으로 갈려 한쪽만 고쳐진 채
> "해결"로 기록됐다([ISSUES #22](../worklog/ISSUES_KR.md)). 한쪽을 고칠 때는
> **"이 로직의 사본이 어디에 더 있나"를 먼저 세는 것**이 규칙이다.

## 7. 현재 상태 (2026-09-09)

- **저수량 산출은 하지 않는다.** 이 저장소도, gee 쪽도 면적까지만 낸다.
- **공식 저수율 자료 경로는 확보됐다.** WAMIS OpenAPI 가 인증키 없이 열려 있고,
  **저수위(`rwl`)·저수량(`rsqty`)·저수율(`rsrt`)** 을 준다. 수집기와 서버 습성은
  [WAMIS_DAM_LEVEL_KR.md](../water/WAMIS_DAM_LEVEL_KR.md).

  ```bash
  python -m s1.tools.wamis.collect_dam_level --preset reservoirs --mode storage
  ```

  ⚠ 저수량·저수율은 **시자료에만** 있다. 일자료로는 안 나온다.
- **H–A–V 곡선은 여전히 없다.** WAMIS 도 주지 않는다. 그러므로 3절의 환산표는
  **불확실도를 보여주는 용도**로만 쓰고, 5-2의 표기 규칙도 **그대로 유효하다** —
  보고서 수치로 옮기지 않는다.
- 대신 5-4의 교차검증 두 가지가 **실행 가능해졌다** — 공표 `rsrt` 와 SAR 면적을
