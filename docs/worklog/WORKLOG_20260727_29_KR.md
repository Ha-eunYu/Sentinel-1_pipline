## Worklog (완료)

1. **SNAP-free RTC(sarsen) 검증** — sarsen 0.9.6 + xarray-sentinel(main)로 이 프로젝트
   S1C COG GRD 지형보정 성공(754B: 유효 39.5%, γ0 dB mean −20.3). 구버전 실패 원인
   (정규식 `s1[ab]`·ns assert)과 해법을 소스로 분석. [RTC_SARSEN_KR.md].
2. **속도 벤치마크 + 교차검증 + DEM 소스** —
   - 754B: **sarsen 16.4분(30m) vs SNAP 27.9분(10m)**; 픽셀당 SNAP 3.7배 빠름(해상도차가
     절대시간 역전 요인).
   - 교차검증(동일 COP30): **지오코딩 완전 정합(시프트 0, r 0.88)**, γ0 dB 중앙값 +0.96.
   - **sarsen 풀씬 메모리 한계**: 정상 길이 IW GRD는 32GB에서 지오코딩 interp OOM →
     `--tc-chunks` 필요(느림) 또는 RAM 증설. SNAP은 타일 스트리밍으로 안정.
   - **DEM 소스 정정**: 자동 Copernicus DEM은 육상 씬 정상(기존 파이프라인 문제 없음).
     벤치마크는 동일 DEM 위해 로컬 COP30 사용. [RTC_BENCHMARK_KR.md].
   - 코드: `benchmark_rtc.py`, `compare_rtc.py`, `_snap_rtc_one.py`, `prepro_grd_gpt.py`(Frost 파라미터).
   - `sarsen_pin`(막다른 env) 삭제.
3. **HW 증설 판단 문서** (`XeonW-2123(...)/` 폴더) — Dell 회신으로 **Precision 5820 Tower 확정**.
   씬당 속도는 **CPU 4코어**가 병목(야간 배치 실측: 출력크기 비례 ~7–86분, 평균 ~41분);
   RAM은 sarsen 풀씬·캐시·안정성(속도 아님); **GPU는 RTC에 무의미**. 메모리 부품
   ECC RDIMM(HMA84GR7CJR4N-WM 32GB / HMAA8GR7AJR4N-XN 64GB). **Dell Service Tag·Case
   번호는 요청에 따라 문서·히스토리에서 제거.**
4. **신규 한반도 6장** — STAC 검색·다운로드(7/25 ×5, 7/26 ×1) → **북한 우선** SNAP Frost
