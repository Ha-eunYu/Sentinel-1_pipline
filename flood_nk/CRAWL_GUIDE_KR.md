# 북한 홍수·기상 크롤링 가이드 (재사용 플레이북)
## NK Flood & Weather Crawl — Playbook / Reference

> 최초 작성: 2026-07-28 · 담당 산출물은 [4장](#4-폴더-산출물-구조) 참조.

## 1. 산출물(무엇을 만드나)

| 파일 | 역할 | 갱신 주기 |
|---|---|---|
| `SPN_오늘의_북한날씨_YYYYMMDD_YYYYMMDD.md` | 일자별 **강수·기온** (SPN/기상청 예보) | 매일/주기적 |
| `North_Korea_flood_damage_crawl_...md` | **홍수 기사 + 경보 + 조선중앙TV 갈무리 + 이미지 레퍼런스** | 사건 발생 시 |
| `NK_FLOOD_WEATHER_INTEGRATED_...md` | 위 둘을 결합한 **통합 타임라인 + 도별 기상** | 위 갱신 후 |

세 파일은 같은 폴더에 두어 상대링크가 유지되게 한다.

## 3. 진행 절차 (Step-by-step)

### 3.1 날씨(SPN) 갱신
1. WebSearch: `SPN 오늘의 북한 날씨 2026년 7월 NN일` 또는 idxno 연속 추정.
2. 각 기사 WebFetch로 **날짜/지역별 강수량/평양·삼지연 최고기온** 추출.
3. `SPN_..._KR.md`의 ① 기간 요약 ② 「한눈에 보기」 표 ③ 일자별 상세 블록 갱신.
4. idxno는 날짜순 증가 → 마지막 수집 idxno+α로 다음 날짜 탐색.

### 3.2 홍수·경보·조선중앙TV 갈무리 갱신
1. WebSearch 검색어(2.4절)로 신규 경보/사건 확인.
2. WebFetch로 **경보 등급·지역·시간당/누적 mm·이미지 URL·캡션** 추출.
3. `North_Korea_..._crawl.md`에 반영:
   - **3A장** = 조선중앙TV/기상수문국 갈무리(시간순, 날짜 기반 헤더 `### MM-DD · 제목`).
   - **4A장** = 남측 수문 사진 + SPN 예방/개황도 이미지.
   - 2장(날짜별 동향 표) · 8장(기사 목록) 행 추가.
4. **이미지는 반드시 임베드**(`![캡션](url)`) + 아래 `[원본](url)` 폴백 링크.

### 3.3 통합본 갱신
1. `NK_FLOOD_WEATHER_INTEGRATED_...md` 2장 타임라인에 새 날짜 행 추가.
2. 3장 강수 국면(phase)·4장 지역 위험·11장 도별 기상(KMA) 반영.
3. SAR 전·후 관측 권장 시점 재평가.

### 3.4 이미지 접근성 검증 (필수)
임베드 전 항상 HTTP 200/이미지 타입 확인:
```bash
for u in URL1 URL2 ...; do
  curl -s -o /dev/null -w "%{http_code} %{content_type} %{size_download}bytes\n" \
    -L --max-time 20 -A "Mozilla/5.0" "$u"
done
```
- 200 + `image/*` 이면 임베드. 404/403이면 URL 재확인 또는 텍스트만.

### 3.5 커밋
- 논리 단위별 커밋(예: "Add KCTV weather special-report section (3A)").
- 파일 이동은 `git mv`로 이력 보존. 기존 워크플로우가 `main` 직접 커밋이므로 동일하게.

## 4. 검색어(쿼리) 템플릿

**날씨:** `SPN 오늘의 북한 날씨 2026년 7월 NN일`
**경보/조선중앙TV:**
- `조선중앙TV 기상수문국 폭우 주의경보 7월 NN일 북한`
- `조선중앙TV 폭우 경보 북한 [지역] 시간당 큰물 갈무리`
- `북한 [태풍명] 폭우 강풍 경보 기상수문국 중부`
**수문:** `북한 황강댐 방류 임진강 필승교 수위 202NMMDD`
**실측/피해:** `북한 최대 NNN.Nmm 폭우` · `북한 큰물 홍수 피해 복구 노동신문`

```
flood_nk/

├─ tools/
│  ├─ nk_crawl.py                                 (재사용 크롤링 툴킷, stdlib)
│  └─ README_KR.md                                (툴 사용법)
├─ SPN_오늘의_북한날씨_20260625_20260721.md         (일자별 날씨)
├─ North_Korea_flood_damage_crawl_20260625_20260721.md  (기사+경보+이미지)
└─ NK_FLOOD_WEATHER_INTEGRATED_20260625_20260721_KR.md   (통합 타임라인)
   (K-water PDF「북한 도별 기상」은 별도 수신 시 여기 보관)
```

### 5.1 재사용 코드 `tools/nk_crawl.py`

수작업 절차 일부를 자동화한 표준 라이브러리 전용 모듈(별도 설치 불필요).

```bash
# 이 환경의 python: C:/Users/chlwn/miniconda3/python.exe
python nk_crawl.py sources                       # 검증된 출처 목록
python nk_crawl.py latest -n 3 --md               # idxno 몰라도 최신 날씨 자동
python nk_crawl.py scan --from 109257 --to 109300 --md   # 구간 스캔(빠름·확실)
python nk_crawl.py spn 109124 109256 --md         # idxno 직접 지정
python nk_crawl.py spn 109256 --check-images      # 파싱 + 이미지 200 검증
python nk_crawl.py verify <img_url> ...           # 이미지 URL만 접근성 검증
```

- **idxno를 모르면 `latest`** (사이트 최신 idxno→아래 스캔) 또는 마지막 수집
  번호를 아는 경우 **`scan --from <그 번호+1> --to <최근>`** 이 빠르다.
  SPN 검색 목록은 날씨를 신뢰성 있게 못 걸러 idxno 스캔 방식을 쓴다.

- SPN 기사에서 **날짜·주요날씨·지역별 강수량·평양/삼지연 기온·이미지 URL**을
  자동 추출(EUC-KR 디코딩 포함). 검증: 07-22~26 5건이 수작업 값과 일치.
- **이미지 임베드 전** `verify`/`--check-images`로 HTTP 200 확인(3.4절 대체).
- 한계: og:description 길이제한 → 본문 태그제거로 보완하지만, 파서 정규식은
  사이트 구조 변경 시 조정 필요. 조선중앙TV/통일뉴스 등 개별 기사는 아직
  수동(WebFetch) — SPN 날씨가 가장 정형화돼 우선 자동화함.

## 6. 북한 기상경보 등급 (해석 기준)

관측된 등급 순서(낮음→높음): **주의경보 → 중급경보**.
- 2026 장마철은 대부분 **주의경보**였고, **07-23 처음으로 '중급경보'**(황해·강원, 시간당 50~80mm)로 격상됨 → 당국 위험 인식 상승 신호.
- 해상/해일도 별도 등급(주의/중급) 발령.
- 「N번째 주의경보」 표현으로 장마철 누적 경보 횟수를 추적 가능(07-20이 4번째).

## 7. 알려진 제약·주의 (다음에도 반복될 이슈)

1. **WebFetch 차단:** `yna.co.kr`(연합) 전면 차단, `voakorea.com` 403. → 재전재본/검색 스니펫으로 우회.
2. **ChatGPT 공유 링크** 자동 수집 불가(로그인/JS) → PDF/텍스트로 직접 수신.
3. **세션/분류기 한도:** WebFetch가 "session limit"·"classifier unavailable" 시 잠시 후 재시도.
4. **사진 provenance:** 국제·국내 기사의 침수 사진이 **남측 군남댐 방류**나 **자료사진**, 또는 **2024년 압록강 대홍수** 영상 재사용인 경우 다수 → 날짜·장소 확인 필수. (2024 수치를 2026에 쓰지 말 것.)
5. **경보 ≠ 피해:** 강수 예보/경보는 위험 신호일 뿐 확정 피해가 아님. 북한 관영매체는 피해를 즉시·정량으로 공개하지 않을 수 있음.
6. **정량 강수 시각:** 기상자료개방포털 북한 관측은 03·15시(6h 누적)/09·21시(12h 누적)만 정량 제공. 18시 등은 현상·기온만.
